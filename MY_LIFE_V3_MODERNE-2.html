Configuration IA

La connexion IA nécessite une URL de backend sécurisée. Ne colle jamais une clé API secrète dans cette page.

Paramètres

Confidentialité, connexion IA et rappels.

Assistant IA

MY LIFE appelle uniquement ton serveur. La clé du fournisseur IA doit rester côté serveur, jamais dans le navigateur.

Le modèle IA est choisi côté serveur par la variable OPENAI_MODEL ; tu n’as pas besoin de le saisir ici.

Le serveur doit répondre avec { "reply": "..." }. La clé API du fournisseur reste uniquement sur le serveur.

Rappels et notifications

Autoriser les notifications du navigateur ne garantit pas des alertes quand le navigateur est fermé. Les rappels locaux ci-dessous fonctionnent pendant que cette page reste ouverte. Pour des notifications Android fiables en arrière-plan, il faut une PWA installée avec service worker et un service push configuré, ou une application native.

Pas encore vérifié.

Protection des données

Les données restent dans le stockage local du navigateur sur cet appareil. Elles ne sont pas chiffrées par cette démo. Évite d'y enregistrer des secrets ou des informations très sensibles. Une suppression du stockage du navigateur peut effacer tes données.

Installer sur Android

Pour installer comme application web (PWA), héberge les fichiers sur un site HTTPS, puis ouvre-le dans Chrome Android et utilise le menu ⋮ → « Ajouter à l'écran d'accueil » ou « Installer l'application ». Ce fichier seul ouvert localement ne peut pas fournir une installation PWA complète ni des notifications push fiables.
